Turn sheet music into note names you can read at a glance: C, D, E, F♯ and so on, measure by measure, with the lyrics underneath.

    Scans need one extra step

    A PDF or photo is a picture of notes, so it first has to be read by a music-recognition program (OMR). Any of these turns it into a MusicXML file you can open here. Recognition is good on clean printed music and makes mistakes on handwriting or blurry photos, so glance over the result.

    1. MuseScore 4 (free): File → Import PDF sends the PDF to MuseScore's free recognition service. When it finishes, download the result as MusicXML and open that file here. Get MuseScore
    2. Audiveris (free, open source, runs offline, PDFs and images): open the scan, let it transcribe, then export as MusicXML (.mxl). From a terminal: Audiveris -batch -export -output out/ song.pdf. Get Audiveris
    3. oemer (Python, photos only): pip install oemer, then oemer photo.jpg writes a .musicxml next to the photo.
    4. Skip scanning entirely: many songs are already available as MusicXML or MIDI on musescore.com, Mutopia and IMSLP.

    Everything runs in your browser; files are never uploaded. Letters show the note as written, including
    sharps (♯) and flats (♭) from the key signature. ~ marks a note tied over from before (keep holding it).
    With octave numbers on, C4 is middle C. Notes stacked on top of each other are played together.
    

    Press Play (or the space bar) to hear it; click a measure number to start from there.
    Only the staves you show are played, in the key you've picked, with repeats followed.
    A pasted Spotify or YouTube link is looked up through this site to get the song's name; their players load only if you press Listen here.
